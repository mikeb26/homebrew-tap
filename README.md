# Homebrew tap for mikeb26

This repository is a Homebrew tap for projects published by [mikeb26](https://github.com/mikeb26).

## Usage

Install a formula directly:

```sh
brew install mikeb26/tap/spotsh
```

Or tap the repository first:

```sh
brew tap mikeb26/tap
brew install spotsh
```

## Available formulae

- `spotsh` - Launch disposable AWS EC2 Spot shell boxes and SSH into them.
